# Quantum Annealing Workshop — INQA 2025

Material and exercises from the quantum annealing workshop organized by Qilimanjaro Quantum Tech during INQA 2025.

## Topics covered

- Quantum annealing and adiabatic computation
- QUBO formulation of optimization problems
- Introduction to D-Wave systems
- Practical examples using Ocean SDK

## Contents

- Jupyter notebooks with exercises and simulations
- Examples of QUBO problem formulation
- Implementation using Python
