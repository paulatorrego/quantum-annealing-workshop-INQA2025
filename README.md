# Quantum Hardware Workshop – INQA 2025

Personal study repository based on the INQA 2025 Quantum Hardware Workshop and QiliSDK introduction material from Qilimanjaro Quantum Tech.

## Contents

- `00_workshop_overview.ipynb`: structured notes from the workshop
- `01_superconducting_qubits_foundations.ipynb`: LC resonator, anharmonicity, avoided crossing, dispersive readout
- `02_fluxonium_scqubits_gap_search.ipynb`: scqubits workflow for tuning fluxonium parameters
- `03_fluxonium_resonator_coupling.ipynb`: resonator parameter conversion and coupling scaffold
- `04_qilisdk_workflows_overview.ipynb`: cleaned notes and code sketches from the QiliSDK deck

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
